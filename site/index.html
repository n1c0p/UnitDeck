What it does

  • System and user servicesTwo tabs, searchable and filterable by state, updated live over D-Bus.
  • Safe editsPackage units get an override.conf drop-in that survives upgrades; every change passes systemd-analyze verify first. "Restore original" reverts.
  • New service wizardTemplates for common cases, validation, optional "enable and start now".
  • JournalLogs of the selected service with follow and priority filter.
  • Terminal interfaceunitdeck-tui, htop-style: same actions on single keys, works on a TTY or over SSH, no Qt inside.
  • Security modelThe interface runs as your user. Privileged actions go through polkit; system unit files are written by a small helper launched with pkexec, limited to a fixed set of operations.

Install

Ubuntu 24.04+ and Debian 13+, Fedora 40+, openSUSE Tumbleweed. Take unitdeck-common plus the interface you want: unitdeck (desktop) or unitdeck-tui (terminal), or both.

sudo apt install ./unitdeck-common_*.deb ./unitdeck_*.deb
sudo dnf install ./unitdeck-common-*.rpm ./unitdeck-*.rpm

The desktop application checks GitHub Releases for updates and installs them on request; it can be turned off in the settings.

Cosa fa

  • Servizi di sistema e utenteDue schede, ricerca e filtro per stato, aggiornate in tempo reale via D-Bus.
  • Modifiche sicureLe unità dei pacchetti ricevono un drop-in override.conf che sopravvive agli aggiornamenti; ogni modifica passa prima da systemd-analyze verify. "Ripristina originale" annulla.
  • Nuovo servizio guidatoTemplate per i casi comuni, validazione, "abilita e avvia ora" opzionale.
  • JournalLog del servizio selezionato con follow e filtro per priorità.
  • Interfaccia da terminaleunitdeck-tui, stile htop: stesse azioni su singoli tasti, funziona su TTY o via SSH, senza Qt.
  • Modello di sicurezzaL'interfaccia gira con il tuo utente. Le azioni privilegiate passano da polkit; i file delle unità di sistema li scrive un piccolo helper lanciato con pkexec, limitato a un insieme fisso di operazioni.
